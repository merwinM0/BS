# 数据预处理说明

## 操作内容

1. **缺失值处理**：
   - 对数值列使用均值填充缺失值。
   - 对分类列使用众数填充缺失值。

2. **异常值处理**：
   - 使用IQR（四分位距）方法检测和移除数值列的异常值。
   - 移除低于Q1 - 1.5*IQR或高于Q3 + 1.5*IQR的值。

3. **连续数据离散化处理**：
   - 对PTS列（假设存在得分列）进行离散化，使用均匀策略分为5个箱子。

4. **标准化**：
   - 对所有数值列应用StandardScaler进行标准化，使均值为0，标准差为1。

5. **相关性分析**：
   - 计算数值列的相关矩阵，并保存到output/correlation_matrix.csv。

6. **数据质量评估与调整**：
   - 初始和最终的数据信息、描述统计和缺失值检查。
   - 确保数据类型正确，移除异常值后的数据质量。

处理后的数据保存到output/processed_data.csv。
